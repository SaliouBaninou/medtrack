# MedTrack logo exports

The logo keeps the heart and pulse mark currently used in the MedTrack interface.

- `medtrack-mark.svg`: symbol only, transparent outside the teal rounded square.
- `medtrack-lockup.svg`: symbol and wordmark for light backgrounds.
- `medtrack-lockup-dark.svg`: symbol and white wordmark for dark backgrounds.
- `medtrack-stacked.svg`: centered symbol and wordmark for compact/mobile layouts.
- `medtrack-app-icon.svg`: full-bleed square source for app icons and splash screens.
- `png/`: raster exports at common favicon, web, and mobile icon sizes.

The SVG sources are resolution independent. PNG exports are provided at 16, 32, 48, 64, 72, 96, 120, 128, 144, 152, 167, 180, 192, 256, 384, 512, and 1024 px for the symbol/app icon, plus 320×80, 640×160, and 1280×320 px wordmarks.
